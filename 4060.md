# Demo laptop runbook (RTX 4060, 16 GB)

We build on another laptop and run the demo here, so the open model runs on our own GPU. Do steps 1–3
**early**, on a hotspot if venue Wi-Fi is slow: they download ~6 GB. Steps 4–7 take ~5 minutes at the end.

Assumes Linux. On Windows, use the Ollama Windows installer and the uv PowerShell installer instead; the
rest is the same.

## 1. GPU driver

```bash
nvidia-smi
```

Should list the RTX 4060 with ~8 GB. If not, install the NVIDIA driver before anything else.

## 2. Ollama + the demo model (~5.2 GB)

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

```bash
ollama pull qwen3:8b
```

```bash
ollama pull qwen3:4b-instruct
```

The 4B instruct (~2.5 GB) is the fallback if the 8B is slow. Don't use the plain `qwen3:4b` tag: it is now a
thinking-only build that spends ~1,000+ tokens reasoning per triage (87 s on the dev laptop). Check the 8B with
`ollama show qwen3:8b`: a context length of 40960 is the hybrid Qwen3 build, which honours `think: false`. Check the GPU is used: run
`ollama run qwen3:8b "say hi"` and watch `nvidia-smi` — memory use should jump by ~5–6 GB.

## 3. uv (Python manager) and the repo

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

```bash
git clone https://github.com/Atharv-tw/sunwai.git && cd sunwai && uv sync
```

## 4. Meko key for this machine

In the Meko portal, Settings → API Keys → generate a key named `sunwai-4060`. Then:

```bash
cp .env.example .env
```

Edit `.env`: paste the key into `MEKO_API_KEY`, set `LLM_MODEL=qwen3:8b`. If `smoke_llm.py` reports p50 above ~10 s, use `qwen3:4b-instruct`. Keep `MEKO_ENABLED=on`.

The product datapacks (`sunwai-*`) belong to whoever's account the key is from. Use a key from the **same
Meko account** that ran the seeded history, or the demo starts with empty memory.

## 5. Smoke tests

```bash
uv run python scripts/smoke_meko.py
```

```bash
uv run python scripts/smoke_llm.py
```

Write the numbers into `result.md` (demo row).

## 5b. Clean, seeded campus (right before the demo)

Stop the app, then empty the product datapacks and load the scripted past cases (`scenarios/history.json`):

```bash
uv run python scripts/reset_product.py --yes
```

```bash
uv run python scripts/seed_history.py
```

Every run of `scenarios/live.json` writes into the product datapacks and promotes the Hostel A geyser lesson
(one-way), so after any rehearsal, reset and seed again. Never delete a datapack to reset it (D-032).

## 6. Run

```bash
uv run sunwai
```

Open http://127.0.0.1:8765 and keep the swarm view on the projector.

Play the demo script (simulated students and staff, badged SCRIPTED), 10 s of real time per scripted minute:

```bash
uv run python scripts/run_scenario.py --speed 10
```

## 7. Before going on stage

- [ ] Laptop on charger, power mode "Performance", sleep disabled
- [ ] `ollama ps` shows the model loaded (run one request first so it is warm)
- [ ] Hotspot connected (Meko is hosted)
- [ ] Browser zoom set so the swarm view fits the projector
- [ ] Meko on/off comparison rehearsed once
- [ ] Reset and seeded after the last rehearsal; the Dean screen shows the RO filter and Block C router patterns
